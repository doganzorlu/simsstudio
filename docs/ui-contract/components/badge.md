# UI Contract Component: Badges & Tag Labels

This document defines status badges and tag labels for resource metadata representation.

---

## 🏷️ Badge Categories
1. **Compression Badges**:
   - `None`: Neutral Grey tag.
   - `Zlib`: Blue tag (`#0284C7`).
   - `RefPack`: Purple tag (`#8B5CF6`).
2. **Issue Severity Badges**:
   - `Info`: Sky Blue badge.
   - `Warning`: Amber badge.
   - `Error`: Red badge.

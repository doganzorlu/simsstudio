# UI Contract Pattern: Module Dashboard & Summary Surfaces

This document defines dashboard layout standards for SIMSStudio.

---

## 📊 Summary Cards & Module Metrics
When presenting package container overviews, dashboards must present summary metric cards:
- **Total Resource Count**: Total number of entries in the container index.
- **Container Type**: Format classification (e.g. `DBPF v2.0`).
- **Total Index Size**: Size in bytes of the container index table.
- **Diagnostic Issues Count**: Count of active warnings or errors.

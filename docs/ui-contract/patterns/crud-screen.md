# UI Contract Pattern: CRUD & Data Entry Screen Standard

This document defines standard CRUD screen conventions for SIMSStudio.

---

## 📝 Usage Context
SIMSStudio is primarily an asset inspection, analysis, and conversion engine. Heavy data-entry CRUD screens are minimal; however, when user input or configuration management is required:
- Form fields must use explicit labels and validation styles.
- Save/Cancel action buttons must be positioned at bottom-right of forms.

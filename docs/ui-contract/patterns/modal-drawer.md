# UI Contract Pattern: Modals & Detail Drawers

This document defines modal dialog and side-drawer patterns for detailed resource inspection.

---

## 🪟 Usage Guidelines
- **Modal Dialogs**: Used for critical operations (e.g. destructive export warnings, settings configuration).
- **Detail Drawers / Flyouts**: Used for displaying deep metadata or raw binary hex dumps for a selected `PackageResourceRow` without leaving the master inspection list.

# UI Contract Governance: Override Rules & Approval Policy

This document defines the governance rules for requesting UI style or control overrides in SIMSStudio.

---

## 📜 Override Approval Workflow
1. **Explicit Justification**: Any custom control template, inline style override, or custom theme brush MUST be justified in the task prompt or technical proposal.
2. **AI1 Governance Review**: Overrides must be submitted to AI1 for explicit approval before merging.
3. **Deviation Logging**: Approved overrides must be logged in [deviation-log.md](deviation-log.md) with Task ID, rationale, and scope.
